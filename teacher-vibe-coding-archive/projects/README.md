# 프로젝트 코드 배치 안내

현재 폴더는 과거 작업 기록을 기준으로 만든 코드 수집 위치입니다.

실제 원본을 찾을 때마다 다음 원칙으로 추가합니다.

1. 프로젝트별 폴더를 만듭니다.
2. 원본을 그대로 넣기 전에 개인정보와 인증정보를 제거합니다.
3. `templates/PROJECT_README_TEMPLATE.md`를 복사해 프로젝트 설명을 작성합니다.
4. `docs/project-catalog.md`와 `project-registry.csv`의 상태를 갱신합니다.
5. 실행 화면을 개인정보가 없는 이미지로 추가합니다.

코드가 아직 연결되지 않은 프로젝트는 빈 폴더를 미리 만들지 않고 목록에서 관리합니다.
