# 개인정보·보안 점검표

GitHub에 올리기 전에 프로젝트별로 확인합니다.

## 학생·학교 정보

- [ ] 학생 이름과 학번을 예시값으로 교체함
- [ ] 전화번호, 이메일, 보호자 정보가 없음
- [ ] 출결, 상담, 성적, 진로 정보가 없음
- [ ] 학교 내부 문서와 비공개 공지가 없음
- [ ] 학생 음성·사진·보고서 원본이 없음

## Google 서비스

- [ ] Spreadsheet ID를 제거함

- [ ] 테스트 계정과 비밀번호를 제거함

- [ ] 외부 라이브러리 출처와 라이선스를 확인함
