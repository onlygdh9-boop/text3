# 수학 풀이 학습실 (5~8번)

공통수학 수업용 반응형 HTML 자료입니다. 문제 원문, 그래프, 단계별 풀이를 제공합니다.

배포 주소: https://onlygdh9-boop.github.io/text3/math-class-5-8/

- `index.html`: 5~8번 문제 선택 화면
- `problem-5.html` ~ `problem-8.html`: 문제별 해설
- `assets/`: 공통 스타일, 동작, 로컬 MathJax 수식 렌더러

기존 `text3` 저장소의 다른 경로는 변경하지 않고 `math-class-5-8/` 경로에만 새 파일을 추가했습니다.

## 배포

`main` 브랜치 변경 시 기존 `.github/workflows/pages.yml`에서 GitHub Pages로 자동 게시합니다.
