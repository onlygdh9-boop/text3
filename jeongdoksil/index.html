사용 순서

  1. 자리와 학생을 입력하고 학생 계정을 발급합니다.
  2. 운영 요일과 제외 일정을 설정한 뒤 해당 월 출석부를 생성합니다.
  3. 출석 담당자는 자리 번호를 보며 해당 교시 결석 학생만 체크합니다.
  4. 학생은 학생용 화면에서 불참 신청을 하고 교사는 승인 여부를 처리합니다.
